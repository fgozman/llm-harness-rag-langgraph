## How to review

For each item check: the question is self-contained and unambiguous, the reference answer is correct for the
cited source(s) (open the file under `data/test_corpus/`, see `sources[].location`), and the category fits.
Then set `"reviewed": true`, fix or delete the line. Editing the file changes its content hash, so the next
`rag eval` uploads it as a new Phoenix dataset version automatically.
